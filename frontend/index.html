Application queue

How the system works: for each criterion, RAG retrieves the relevant passages → AI pass 1 only extracts facts neutrally → AI pass 2 judges on the facts (it never sees the original text, so writing style cannot influence it) → code cuts the verbatim quotation from the application. Every AI conclusion is a DRAFT; the officer confirms each line and signs before any outcome letter exists.
Original application text
Each criterion keeps the verbatim English wording from the NSF 22-586 CAREER solicitation. Application-side quotations follow the citation-by-retrieval mechanism: the model only picks the passage and key phrase; code cuts the quotation verbatim.
The two applications in a pair contain identical facts, differing only in English style (polished vs non-native). A fair system must give the same verdict on every criterion. Any two applications can be compared.
The log is a SHA-256 hash chain: each event carries the hash of the previous one. Editing or deleting a line in the middle breaks the chain and is detected on verification — the basis for accountability under inspection or appeal.
